## 1. 函数的定义与元素

从本质上来说函数算是一种二元关系，有正经的名字描述其行为：

设函数 $`f`$ 是从集合 $`X`$ 到集合 $`Y`$ 的二元关系，此处集合 $`X`$ 为 $`f`$ 的“**出发集合**”，集合 $`Y`$ 为 $`f`$ 的“**陪域**”。字面意义上理解，$`f`$ 包含的全部有序对都满足左元素属于 $`X`$，右元素属于 $`Y`$。更精确地说，所有左元素构成的集合是 $`X`$ 的一个子集，这个集合的学名为 $`f`$ 的**定义域**（$`\operatorname{dom} f`$），与此同时所有右元素也构成 $`Y`$ 的一个子集，学名为 $`f`$ 的**值域**（$`\operatorname{ran} f`$）。

传统意义上的函数在我们的印象中是具有“一个 $`x`$ 只能对应唯一一个 $`y`$”的特性的，这个性质在此可以严格阐述为“**单值性**”，具有单值性的函数则成为“**部分函数**”。也就是说，平时讨论的函数（默认为部分函数）一般是不会出现从一个 $`x`$ 向多个 $`y`$ 发出连线的情况的，然而一个 $`y`$ 收到从多个 $`x`$ 发来的连线倒是可以实现。

```math
\forall y_1\forall y_2(f(x)=y_1 \land f(x)=y_2 \to y_1=y_2)
```

```math
\exists x_1\exists x_2(f(x_1)=y \land f(x_2)=y)
```


说到这里自然就产生了分类讨论的操作空间——所谓子集是真包含还是相等？由此引出了几种不同情况：

1. $`\operatorname{dom} f`$ 等于 $`X`$。此时 $`X`$ 中的每个输入（左元素）都有与之对应的输出（右元素），满足条件的 $`f`$ 为**全函数**；
2. $`\operatorname{dom} f`$ 真包含于 $`X`$。此时 $`X`$ 中存在一些输入没有与之对应的输出，满足条件的 $`f`$ 为**严格部分函数**；
3. $`\operatorname{ran} f`$ 等于 $`Y`$。此时 $`Y`$ 中的每个输出都有与之对应的输入，满足条件的 $`f`$ 为**到 $`Y`$ 上的部分函数**；
4. $`\operatorname{ran} f`$ 真包含于 $`Y`$。此时 $`Y`$ 中存在一些输出没有与之对应的输入，满足条件的为**到 $`Y`$ 内的部分函数**。

然而很多时候我们考虑函数相关的问题并不只局限于一个固定的定义域。于是变换定义域并随之更新值域的动作便应运而生。

**限制**：把函数的定义域缩小到某个更精确的范围。严谨表述，函数 $`f`$ 在集合 $`A`$ 上的限制 $`f\vert_A`$ 是一个衍生的新函数，其构造过程是选取了 $`f`$ 中所有满足“左元素属于集合 $`A`$”的有序对，也即 $`f\vert_A`$ 的定义域是 $`A`$ 与 $`\operatorname{dom} f`$ 的交集。当然，这里要求集合 $`A`$ 本身就先是出发集合 $`X`$ 的一个子集。

```math
f|_A=\{y|\exists x(x\in A\land f(x)=y)\},A\subseteq X
```


**延拓**：把函数的定义域扩大到某个更丰富的范围。严谨表述，函数 $`f\vert_A`$ 到 $`X`$ 的延拓就是 $`f`$，相当于限制的一个逆变换结果。

现在我们已经拥有了可放缩的定义域 $`A`$，与之配套的新值域则称为“**像**”。集合 $`A`$ 的像 $`f[A]`$ 是陪域 $`Y`$ 的一个子集，其构造过程是选取了 $`f`$ 中所有满足“左元素属于集合 $`A`$”的有序对的右元素，进而说明 $`f[A]`$ 也是 $`f`$ 的值域 $`\operatorname{ran} f`$ 的一个子集。

```math
f[A]=\{y|\exists x(x\in A\land f(x)=y)\},f[A]\subseteq \operatorname{ran} f
```

在这个定义之中，从右元素$`y`$集合 $`f[A]`$ 返回相应的左元素$`x`$集合称为源像，经 $`f`$ 的逆变换 $`f^{-1}`$ 得到的结果 $`f^{-1}[f[A]]`$ 即为 $`f[A]`$ 的“**源像**”。它也是定义域$`\operatorname{dom} f`$的一个子集。

```math
f^{-1}[f[A]]=\{x|\exists y(y\in f[A]\land f(x)=y)\}
```

但正如上面所说，一 $`y`$ 对多 $`x`$ 的情况在函数中十分常见，因此从一个 $`x`$ 出发到达 $`y`$，从 $`y`$ 再返回有很多源头可选，就不一定是回到原先这个 $`x`$ 了，从而导致源像的范围比成像集合更大，也即 $`A`$ 是 $`f^{-1}[f[A]]`$ 的一个子集。

```math
A\subseteq f^{-1}[f[A]]
```

由于单值性的限制，从像返回源像再出发并不会产生原先像以外的新输出，因为源像中所有的输入都已经只锚定像中唯一的输出了，所以以源像为成像集合变换得到的新像与原先像相同。

```math
B=f[f^{-1}[B]]
```


根据定义可以发现两个自然成立的结论：

```math
f[X] = \operatorname{ran} f, \qquad f^{-1}[Y] = \operatorname{dom} f.
```

另外规定了 

```math
f[\varnothing] = \varnothing
```

最后，在同时考虑很多个成像集合/像集合的广义交并时，基本是满足“先交并再变换=先变换再交并”的。

```math
\begin{aligned}
f\left[\bigcup \mathcal A\right]
&= \bigcup_{A\in\mathcal A} f[A], \\[6pt]
f\left[\bigcap \mathcal A\right]
&\subseteq \bigcap_{A\in\mathcal A} f[A],
&& (\mathcal A\ne\varnothing), \\[6pt]
f^{-1}\left[\bigcup \mathcal B\right]
&= \bigcup_{B\in\mathcal B} f^{-1}[B], \\[6pt]
f^{-1}\left[\bigcap \mathcal B\right]
&= \bigcap_{B\in\mathcal B} f^{-1}[B],
&& (\mathcal B\ne\varnothing).
\end{aligned}
```

至于第二条中“先交再成像”的范围可能比“先成像再交”的范围小一点，这是因为成像集合的交集可能是空集，从而导致左边的像也是空集，但此时如果成像集合中有输出相同的输入，右边的像集合就有了广义交的共同元素，不是空集，故而两边不等。这也暗示了对于一些输入与输出一一对应的函数，不存在多个输入共享一个输出的情况，其等式左右两边应当是相同的，

## 2.函数的划分与性质
上一节对函数的分析，是分别关注出发集合$`X`$与陪域$`Y`$之中的范围，但我们不妨把起点和终点联合起来看。在开始之前，先进行一个基本的设置：以下讨论的函数$`f`$均为**全函数**。


我们知道，有些函数的定义中会出现值域$`\operatorname{ran} f`$等于陪域$`Y`$的情况，这意味着集合$`Y`$中所有元素$`y`$都满足集合$`X`$中至少存在一个元素$`x`$，使得$`x`$是它的出发点。

```math
f是满射
```

```math
\Leftrightarrow \operatorname{ran} f= Y 
```

```math
\Leftrightarrow \forall y(y\in Y \to \exists x(x\in X\land f(x)=y))
```

满足上面这种情形的函数$`f`$是**满射**。顾名思义，在输出布满整个陪域的条件下，这类函数具有的性质是：所有的输出拥有至少一个与之对应的输入。

与之相对的，当值域$`\operatorname{ran} f`$不等于陪域$`Y`$时，集合$`Y`$中存在元素$`y`$满足集合$`X`$中的所有元素都不是它的出发点。

```math
f不是满射
```

```math
\Leftrightarrow \operatorname{ran} f\subset Y 
```

```math
\Leftrightarrow \exists y(y\in Y \land \forall x(x\in X\to f(x)\neq y))
```

上面这种情形就是对$`f`$是满射的否定了。由此可以联想到：倘若需要证明一个函数$`f`$是满射，有时候可以通过反证法构造出一个不对应任何输入$`x`$的输出$`y`$，再反推出矛盾，从而证明$`f`$不为满射的情况不成立。

讨论完输出比较均匀分散的情况，与此同时另外一边，输出是否拥挤集中也决定了一个特殊性质。

对于函数$`f`$定义域内的任意两个输入$`x_1`$和$`x_2`$，其对应的两个输出$`y_1`$和$`y_2`$可以相等，也可以不相等。前面提到的**单值性**禁止了一个$`x`$对应多个$`y`$的情况，假如在这个基础上再补充禁止一个$`y`$对应多个$`x`$的约束，我们会发现这样的函数包含的全部有序对都不存在右元素两两相同的情况（当然也不存在左元素两两相同的情况），更确切地说，所有有定义的输入$`x`$与输出$`y`$都是一一对应的。

```math
f是单射
```

```math
\Leftrightarrow \forall x_1\forall x_2(x_1,x_2 \in X \land f(x_1)=f(x_2)\to x_1=x_2)
```

满足上述条件的函数$`f`$是**单射**。再次顾名思义，在每个输出不同时对应多个输入的情况下，这类函数具有的性质是：所有的输出拥有至多一个与之对应的输入。（不在值域内的输出对应$`0`$个输入）

从上面构造单射的假设中可以看出，其反面情形便是存在两个有定义的不同输入$`x_1`$和$`x_2`$使得它们的输出相同。

```math
f不是单射
```

```math
\Leftrightarrow \exists x_1\exists x_2(x_1,x_2\in X \land x_1 \neq x_2 \land f(x_1)=f(x_2))
```

同样地，如果希望用反证法证明一个函数$`f`$是单射，也可以构造两个共享相同输出的不同输入$`x_1,x_2`$，再推出矛盾，从而证明$`f`$不为单射的情况不成立。

进行至此，我们很自然地想到了一些既是单射又是满射的函数，其输出同时具有“至多对应一个输入”和“至少对应一个输入”的性质，好像用人话来说就是“每个输出都对应一个输入”的意思。

```math
f是双射
```

```math
\Leftrightarrow f是单射 \land f是满射
```

同时是单射和满射的函数是**双射**。

全函数和满射的要求保证了定义域等于出发集合且值域等于陪域，单射的要求又使得定义域和值域的元素数量必须相同，因此双射还具备出发集合与陪域的元素数量相同的性质。

```math
f：X\to Y是双射\Rightarrow |X| = |Y|
```


## 3.函数的复合及其运算
作为一种特殊的二元关系，不同的函数之间当然也可以进行名为**复合**的关系运算。

```math
(g\circ f)(x)=g(f(x))
```


正如二元关系的复合所要求的，进行复合的两个函数必须满足左函数的陪域与右函数的出发集合相同，更精确的限制是左函数的值域包含于右函数的定义域。这是因为如果左函数值域的范围比右函数定义域的范围大，必然会存在一些左函数的输出在作为右函数的输入时没有定义，可以算是左函数定义域（即整个复合函数的定义域）的失职。

```math
f:X\to Y
```

```math
g:Y\to Z
```

```math
(g \circ f)存在\Rightarrow\operatorname {ran}f\subseteq \operatorname {dom} g
```

这就是函数复合需要的满足的前提条件了。由上也能发现，复合函数的定义域与最内层函数的定义域相同，值域与最外层函数的值域相同，显而易见的原因是：最内层函数$`f`$是唯一从整体出发集合$`X`$接收输入的，最外层函数$`g`$是唯一向整体陪域$`Z`$传递输出的。

函数$`f`$与其自身的复合学名也叫**幂**，把$`f`$分别代入上文中左函数与右函数的位置，即得到幂存在的要求：$`f`$的定义域与值域相同。

```math
(f \circ f)存在\Rightarrow\operatorname {ran}f\subseteq \operatorname {dom} f \land \operatorname {dom}f\subseteq \operatorname {ran} f\Rightarrow \operatorname {ran}f= \operatorname {dom} f
```

定义在集合$`X`$上的恒等函数$`I_X`$便是定义域与值域均为集合$`X`$的函数$`f`$的**0次幂**。

```math
f:X\to X
```

```math
f^0=I_X=\{x|x\in X\land f(x)=x\}
```

```math
f^0\circ f = f
```

由于有幂的函数$`f`$满足任意次幂的定义域与值域均不变且相同，其可以同时成为与幂复合中的左函数或右函数，因此有：

```math
f^{m}\circ f^{n}=f^{n}\circ f^{m} = f^{n+m}
```

事实上，“与恒等函数复合的结果仍为原函数”的性质可以推广到一般函数的情况，但左复合与右复合需要的恒等函数并非同一函数。假设$`f:X\to Y`$是从集合$`X`$到集合$`Y`$的函数，左复合时恒等函数为外层函数，其值域需要与目标结果$`f`$的值域相同，则此恒等函数必须定义在$`Y`$上。反之，右复合时恒等函数为内层函数，其定义域需要与目标结果$`f`$的定义域相同，则此恒等函数必须定义在$`X`$上。

```math
I_Y\circ f = f
```

```math
f\circ I_X=f
```

但是对于一般函数之间的复合，交换律显然是一般不成立的，因为交换次序后整体的定义域变成了原先外层函数的定义域，整体的值域变成了原先内层函数的值域，整体的输入输出传递方向被完全翻转了。不过结合律还是可以无条件实现的，毕竟结合律不改变多个函数之间的相对位置顺序。

```math
f\circ g \neq g \circ f
```

```math
(f\circ g)\circ h =f\circ (g\circ h) 
```

最后来到了我们比较关心的一个问题：复合函数是否保留各函数原先的性质（单射/满射/双射）呢？
这里可以先暂停思考一下单射和满射的关注点侧重于哪个集合。

根据第2节的推断，单射需要出发集合中不存在不同输入产生相同输出的情况，换而言之，若要使复合函数不为单射，必须从整体定义域抓起。假如决定整体定义域的最内层函数不为单射，则存在最内层函数的不同输入产生相同输出，这些相同输出依次经过所有外层函数而保持相同，最终到达最外层函数时作为输入的次外层输出仍然相同，因而最外层函数的输出也相同，从整体来看就是复合函数也存在不同输入产生相同输出，复合函数也不为单射。其逆否命题为真，即复合函数为单射可以推出最内层函数为单射。

```math
f_1\circ f_2\circ ... \circ f_n为单射\Rightarrow f_n为单射
```

同样考虑满射的要求。满射需要陪域中不存在输出没有对应输入的情况，也就是说，若要使复合函数不为满射，必须从整体值域倒推。假如决定整体值域的最外层函数不为满射，则存在最外层函数的某个输出没有与之对应的输入，这个悬空的输入必然是在某个中间函数处中断的，但不论如何都无法与最内层函数的整体输入连接上，故复合函数也存在输出没有对应输入的情况，复合函数也不为满射。再取逆否命题，即复合函数为满射可以推出最外层函数为满射。

```math
f_1\circ f_2\circ ... \circ f_n为满射\Rightarrow f_1为满射
```

于是复合函数是双射时的推论也就不证自明了：最内层函数为单射且最外层函数为满射。这个说法也可以概括为**左满右单**（最左边的函数是满射，最右边的函数是双射）。

```math
f_1\circ f_2\circ ... \circ f_n为双射\Rightarrow f_n为单射 \land f_1为满射
```

不过呢要是想从每个参与复合的函数性质推断出整体复合函数的性质大概是十分困难的，毕竟任意一个环节都可以插入某个对应关系非常极端的函数（比如所有输入对应同一个输出）而导致整体复合函数的性质也变得比较奇怪。（那我们把充分条件也设置得极端一点不就可以了嘛）

```math
f_1,f_2,...,f_n全为单射\Rightarrow f_1\circ f_2\circ ... \circ f_n为单射
```

```math
f_1,f_2,...,f_n全为满射\Rightarrow f_1\circ f_2\circ ... \circ f_n为满射
```

```math
f_1,f_2,...,f_n全为双射\Rightarrow f_1\circ f_2\circ ... \circ f_n为双射
```

（好像比较显然。）

## 4.函数的可逆及其求解
在第一节中我们提到过由函数$`f`$的像恢复到源像的变换$`f^{-1}`$，然而这个语境中的“逆变换”只是找了传统意义上的逆关系把所有有序对中的$`y`$换成$`x`$，$`x`$换成$`y`$，$`(x,y)`$换成$`(y,x)`$而已，并没有结合函数本身的映射特征来考虑。

其实函数意义上的可逆与矩阵意义上的可逆有些许相似之处，具体表现为：运算都有左右之分，目标都是合成恒等。

定义全函数$`f:X\to Y`$，如果想要确定一个函数$`l`$通过左侧复合于$`f`$得到恒等函数,即有：

```math
l\circ f = I_X\Leftrightarrow l(f(x))=x
```

此时$`l`$的作用是把值域中给定的输出$`f(x)`$恢复为其对应的唯一输入$`x`$，其学名为$`f`$的**左逆**，出发集合为$`Y`$，值域为$`X`$。

由$`l`$作为部分函数的单值性要求可以发现，当$`f`$不为单射时，存在某个输出$`y`$同时对应多个输入$`x_1,x_2,...,x_n`$，$`l(y)`$的值究竟是不是原先输入的$`x`$就无法确定了，因而这种情况下满足条件的$`l`$不存在，其真逆否命题是：$`l`$存在时$`f`$为单射。反过来看，当$`f`$为单射时，所有的有定义输入$`x`$都对应唯一的输出$`y`$，那么我们只需要把$`f`$中的有序对左右元素全部交换，就得到了一个从值域到定义域的新函数$`l`$，且满足左逆的性质，即：$`f`$为单射时$`l`$存在。

综上，我们发现了一个很有应用价值的结论：

```math
f有左逆\Leftrightarrow f是单射
```

判定$`f`$的左逆不存在时，可以观察有没有一个$`y`$对应多个$`x`$的情况，若存在则无左逆。

同理，对于$`f`$的右侧复合也可以设计一个函数$`r`$，使得复合结果为恒等函数：

```math
f\circ r=I_Y\Leftrightarrow f(r(y))=y
```

此时$`r`$的作用是把值域中给定的输出$`y`$恢复为其对应的输入之一，再由$`f`$作用返回$`y`$，其学名为$`f`$的**右逆**，出发集合为$`Y`$，值域为$`X`$。

与左逆不同的一点是，右逆的恢复目标是给外层$`f`$随便找一个可以产生$`y`$的输入，即使中间$`r(y)`$的值不唯一，也不影响外层函数$`f`$将其映射为原本的$`y`$，所以右逆并不要求$`f`$是单射。那什么情况下右逆会不存在呢？对比一下左逆复合的过程，是先由有定义的$`x`$产生有对应输入$`x`$的输出$`f(x)`$，再交给$`l`$作用还原为$`x`$，这里保证了$`l`$接收的值均为有对应输入的输出，因而不需要考虑输出悬空的问题。

但右逆就不一样了，$`r`$直接从陪域$`Y`$里获取输入，如果拿到了没有对应输入的悬空输出，就无法恢复到任何输入值，进而破坏了复合的完整性。因此确定右逆要求$`f`$的每个输出都必须有对应输入，即$`f`$必须为满射。反过来看，当$`f`$为满射时，可以从每个输出$`y`$的若干个来源中随便选择一个$`x`$作为$`r(y)`$的值，这样就构造出了一个右逆$`r`$，即：$`f`$为满射时$`r`$存在。

综上，我们又发现了另一个很有应用价值的结论：

```math
f有右逆\Leftrightarrow f是满射
```

判定$`f`$的右逆不存在时，可以观察有没有一个$`y`$不对应任何$`x`$的情况，若存在则无右逆。

事已至此，很难不幻想坐拥单射性质与满射性质的双射在可逆性领域会是什么强度的存在。实则当双射$`f`$同时满足左逆$`l`$存在和右逆$`r`$存在时，应用一些结合律可以得到下面的等式：

```math
l =  l \circ I_Y = l \circ (f \circ r)=(l\circ f)\circ r = I_X \circ r =r 
```

双射的左逆和右逆居然是同一个函数，我们可以把这个天命所归的新函数称为$`f`$的**逆**$`：f^{-1}`$。不过既然是天命所归必须独一无二，假设还有另外一个函数$`g`$也满足$`g`$为$`f`$的逆，则会发生这样的事情：

```math
g = g \circ I_Y = g \circ (f \circ f^{-1})=(g \circ f)\circ f^{-1}=I_X\circ f^{-1}=f^{-1}
```

因此$`f`$的逆$`f^{-1}`$是唯一的。这个逆同时拥有左逆和右逆的运算性质，其存在则说明**f是可逆的**。

最后还有一些关于逆的运算结论：

```math
f有左逆\Leftrightarrow (f\circ u =f\circ v \to u=v)\Leftrightarrow f可左消去
```

```math
f有右逆\Leftrightarrow (u\circ f =v\circ f \to u=v)\Leftrightarrow f可右消去
```

```math
(f\circ g)^{-1}=g^{-1}\circ f^{-1}
```


## 5.函数在集合论中的应用——特征函数
这个部分实际上是交并补差之类的神秘集合运算的延申，有时候在解决小众集合运算等式证明题的时候可能有用。（当然大概是故意要求你“使用选定的方法抵御进攻”）

假设把一个集合$`A`$所属全集$`U`$的所有元素视为某个函数的定义域，每个元素都可以代表此函数的一个输入，而其输出只能在$`0`$和$`1`$之中选择其一，前者代表这个元素不在集合$`A`$中，后者代表这个元素在集合$`A`$中，这样就构造出了独属于集合$`A`$的**特征函数**$`\chi_A:U\to R`$。

```math
\chi_A(x)=0,x\notin A
```

```math
\chi_A(x)=1,x\in A
```

```math
\chi_A(x)=\chi_A^{n}(x),n\in N
```

```math
(0^{n}=0,1^{n}=1)
```

这个转换的意义在于确定了一种从宏观角度定量描述集合范围的方法，并且还衍生出一个重要的道理：若两个集合的特征函数相等，则其取值在全集定义域上逐点相等，即两个集合覆盖的元素与不覆盖的元素完全相同，因此两个集合相同。

```math
 \chi_A(x) = \chi_B(x)\Leftrightarrow A=B
```

再补充上用特征函数运算表示集合运算的方式，我们就可以将集合运算等式的证明完全转变为特征函数多项式的代数证明了。

```math
\chi_{C_UA}=1-\chi_A
```

```math
\chi_{A\cap B}=\chi_A \chi_B
```

```math
\chi_{A\cup B}=\chi_A+\chi_B-\chi_A \chi_B
```

```math
\chi_{A-B}=\chi_A(1-\chi_B)
```
